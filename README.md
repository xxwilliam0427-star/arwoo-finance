# Arwoo 财务助手

一个纯本地运行的个人财务助手：三大账户池 + 分板块报表。不需要联网、不需要安装依赖、不需要账号。

## 怎么用

1. 双击 `启动助手.bat`
2. 浏览器会自动打开 `http://127.0.0.1:8787`
3. 用完后把那个黑色窗口关掉即可

> 如果双击后窗口一闪而过，说明电脑上还没有装 Node.js，去 https://nodejs.org 装一下 LTS 版就行。

## 数据放在哪

- 全部数据：`data/finance.json`
- 自动备份：`data/backups/`（每次记账保存前都会自动存一份，保留最近 200 份）
- 换电脑或者想留底：在「设置」里点「导出备份」，会下载一个 json 文件；在新电脑的「设置」里点「导入备份」即可还原

## 三个账户池

| 账户池 | 放什么 |
| --- | --- |
| 日常现金池 | 货币基金、银行活期，随取随用 |
| 中短期目标池 | 房租、旅游、买车等目标，可以设目标金额和进度 |
| 长期金鹅池 | 长期投资账户，可以记录投入成本和当前市值，看盈亏 |

## 主要功能

- 记账：收入 / 支出 / 账户间调拨 / 余额校准，都能改能删
- 截图导入：把支付截图批量拖进来，自动认出金额、日期、收付方向、商户，认错的随手改
- 分类和备注：内置常用分类，也能自己加
- 账户：银行卡、活期存款、货币基金、基金、股票、其他
- 每个池都可添加新账户或选择已有账户；同一账户可加入多个池，余额和流水共用，总资产只计算一次。各池金额可能重叠，不能直接相加；共用账户可通过「移出此池」移除关联。
- 目标：目标金额 + 截止日期 + 进度条
- 报表：月度收支、支出分类占比、收入分类占比、近 12 个月走势、资产趋势
- 设置：分类管理、导入导出、载入示例数据、清空数据

## 批量导入支付截图

顶部「截图导入」页 —— 支持三种投喂方式：

- 直接把图片拖到虚线框里
- 点「选择截图」一次选多张
- 在页面上直接 Ctrl+V 粘贴

每张截图会自动识别出**金额、日期、是支出还是收入、商户名**，并按内容猜好**分类和账户**。
识别不准或者没认出来（比如截图太模糊）都可以直接在下面对应的框里改，改完点「一起入账」批量进账本。

一次传一批（比如攒了一周的）、跨好几天也没问题：底部会显示这批截图**覆盖的日期范围**和收支合计，
嫌乱可以点「按日期排序」把它们按时间顺序排好，再逐条核对入账。

识别用的是 **RapidOCR**（PaddleOCR 的离线轻量版），中文识别很准，而且**完全在本机运行**：

- 图片不会上传到任何地方，也不会存进账本，识别完就丢掉了
- 引擎常驻内存，模型只加载一次，之后每张图 1~2 秒
- 一次导入建议不超过 30 张

识别引擎装在 `tools/ocr-env/` 这个独立环境里，不会动你系统里的 Python。
如果换电脑或者这个文件夹被移动过，双击 `tools/安装识别引擎.bat` 重装一下即可（需要联网下载约 200MB）。
万一引擎没装好，程序会自动退回 Windows 自带的识别，并在页面上标出来提醒你核对。

识别的一些细节：金额优先取带 ¥ 或 ￥ 的那一行、并且取字号最大的（付款截图里金额字最大）；
OCR 偶尔会把 1 认成 L、把「余额宝」认成「余额」，这两种情况都做了容错。

## 手机访问

程序启动后同时监听本机和局域网，**手机不用装 App**，浏览器打开就能用：

1. 手机连上和电脑**同一个 WiFi**（不要用流量）
2. 手机浏览器打开 `http://<电脑IP>:8787/`——具体网址在「设置 → 手机访问」里，
   启动时那个黑窗口也会打印出来
3. 第一次会让你输一个 **6 位配对码**（同一页上），输一次就记住了
4. 想更像 App，可以在手机浏览器里选「添加到主屏幕」

界面会按手机屏幕自动变成单列布局，记账表格可以左右滑动。

**手机打不开？** 多半是 Windows 防火墙拦了。双击 `tools/开启手机访问.bat`
（会弹一次管理员确认），它负责放行 8787 端口，只对家里的局域网生效。

**要不要一直开着电脑：要。** 这个助手本质上是跑在你这台电脑上的小网站，电脑关机手机就连不上；
而且上面这个网址只在同一个 WiFi 下有效，出门用不了。

想出门也能用、或者电脑经常关着，只有两条路：

- **装 Tailscale**（免费）：电脑和手机各装一次，出门用流量也能连回家里的电脑，
  走加密专线、不暴露到公网。缺点依然是电脑得开着。
- **搬到云服务器**：电脑可以彻底关机，但每月要花钱租服务器，财务数据也会离开你家。

## 飞书自动收图（可选）

如果你习惯把支付截图发到飞书，可以让程序自动去收，省掉手动选文件这一步：

1. 「设置」→「飞书自动收图」，展开里面的步骤说明，按提示去飞书开放平台建一个自建应用
   （一次性，约 3 分钟）：加「机器人」能力、开通 `im:message` 和 `im:resource` 权限、
   订阅方式选「**使用长连接接收事件**」并添加事件「接收消息 `im.message.receive_v1`」、发布版本。
2. 把拿到的 **App ID / App Secret** 填进「设置」，勾上「启用」，保存。
3. 在飞书里把支付截图**发给这个机器人**（单聊或拉个群都行）。

之后每次打开「截图导入」页，机器人收到的图会自动出现在待识别列表里，跟手动拖进去的待遇完全一样。

几个要点：

- **为什么要建应用**：飞书不允许第三方读你「发给自己」的消息，机器人只能读到发给它的消息，
  所以是「发给机器人」，不是「发给自己」。
- **长连接**：本机主动连出去，不需要公网地址、不需要域名、不需要内网穿透。
- **凭据存放**：App ID / App Secret 单独存在 `data/feishu.json`，**不进账本、不进备份文件**，
  导出备份时不会带出去。想删掉点「清除凭据」。
- **断线自动重连**：连不上会自己重试 5 次，界面上能看到具体原因。
- **电脑关机期间发的截图会补回来**：飞书的长连接是实时推送、不排队，关机期间推送不到；
  但消息还在会话历史里，程序启动后会自动往回翻一遍，把没处理过的截图捡回来。
  翻的时候靠「这条消息处理过没有」判断，所以重复启动不会重复收。

  > 前提：机器人得先「认识」这个会话。所以**第一次要先在电脑开着的时候给机器人发一条消息**，
  > 之后关机期间发的才能补回来。没发过的话，设置页会提示「给机器人发一条消息后就能补收了」。

## 文件结构

```
server.js          本地服务（零依赖）
启动助手.bat        双击启动
web/               网页界面
data/              你的数据（自动生成）
tools/selftest.js  算法自检脚本
tools/ocr_rapid.py 截图识别（RapidOCR）
tools/ocr.ps1      备用识别（Windows 自带）
tools/feishu_bot.py 飞书机器人长连接（收图）
tools/开启手机访问.bat  放行防火墙，让手机能连上
tools/ocr-env/     识别引擎的运行环境（约 400MB，可删，用安装脚本重建）
tools/安装识别引擎.bat  换电脑后重装识别引擎
```

## 想验证数字算得对不对

在本文件夹打开命令行，运行：

```
node tools/selftest.js
node tools/form-selftest.js
node tools/pool-selftest.js
node tools/valuation-selftest.js
```

它会检查余额、调拨、目标进度、市值盈亏、报表这些计算是否自洽（全部通过会显示「通过 N 项，失败 0 项」）。
金额表单回归测试还会检查编辑后保存、修改金额及表单重绘时金额是否保持正确。
加上 `--state data/finance.json` 还可以顺便体检你的真实数据：

```
node tools/selftest.js --state data/finance.json
```
